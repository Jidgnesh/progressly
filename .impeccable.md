## Design Context

### Users
Personal productivity tool, primarily used by the creator on phone and laptop. May extend to a small number of users in the future. Context: daily task management — checking in on progress, adding tasks on the go, reviewing what got done.

### Brand Personality
Calm, focused, minimal. The interface should feel like a quiet workspace — present what matters, hide everything else until needed.

### Aesthetic Direction
- **Visual tone:** Refined minimalism with purposeful accents. Inspired by Linear — clean surfaces, restrained color, confident typography, smooth interactions that feel considered rather than decorative.
- **Theme:** Dark and light mode. Dark is the primary personality (slate + violet), light is a clean alternative.
- **Anti-references:** Not cluttered. No enterprise dashboard feel. No information overload. No Jira.
- **Color:** Violet accent (#7c3aed) is the brand color. Priority colors (red/amber/green) are functional, not decorative.

### Design Principles
1. **Show less, mean more** — Every element earns its place. Progressive disclosure over information density.
2. **Motion with purpose** — Animations communicate state changes and provide feedback. Never decorative-only.
3. **Touch-first confidence** — Every interactive surface feels responsive and intentional. Press feedback on everything.
4. **Quiet until needed** — Secondary information (stats, metadata, controls) stays hidden until the user asks for it.
5. **Consistent calm** — Same spacing rhythm, same easing curves, same depth system everywhere. Cohesion creates calm.
